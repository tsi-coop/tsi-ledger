Ops Console Tour

TSI Ledger - one organization-wide ledger

Every App (HRMS, Commerce, Lending, ...) posts double-entry journal entries via its own API key, always against one shared Chart of Accounts. This walks through the console modules in the order you'd typically touch them.

1

System Setup

The very first time the console runs, there's no one to log in as. setup/init.html creates the first Admin account. After that it 409s - every other account is created from the Users module.

2

Login

Email + password, same as any normal application login. There's no shared master key - every action in the console is attributed to a real operator.

3

Users Admin

Admins create and manage Operator and Admin accounts for the accounts team, reset passwords, and deactivate access.

4

Apps & API Keys Admin

Each posting source (HRMS, Commerce, Lending, ...) is provisioned here as an "App" with its own live/test API key. Keys are shown exactly once, at creation or rotation - the console never stores or re-displays them.

5

Chart of Accounts

One shared list of accounts for the whole organization - not per-App. Admins create/deactivate accounts; everyone can browse them. Every App posts against this same chart.

6

Posting Entries (API)

Apps post balanced double-entry journal entries directly to the API with their own X-API-Key - this never goes through the browser console. Each App's postings form their own tamper-evident, hash-chained sequence.

7

Manual Entries & Reversal Requests

Operators can post manual correcting entries from the console and request a reversal of any posted entry with a reason. A request doesn't post anything by itself.

8

Reversal Approvals Admin

Maker-checker: a different Admin than the requester must approve before the offsetting entry actually posts. An App reversing its own entry via its API key skips this - that's an automated correction, not a manual one, so it posts immediately.

9

Audit Verification

Recomputes the SHA-256 hash chain for one App from the currently stored data and compares it to what was recorded at post time - catches any out-of-band tampering.

10

Reports & Raw Export

Trial balance and balance sheet, combined across every App by default (or filtered to one). Download the full raw journal-entry ledger as CSV for reconciliation or import elsewhere.
